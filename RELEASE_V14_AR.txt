منصة الطالب الصامد — v14 إصلاح واجهة Streamlit
================================================

هذا الإصدار يصحح الخلل المرئي الذي ظهر في Dashboard عند تشغيل المنصة عبر Streamlit.

ما صُحح:
- لم تعد الواجهة تفتح حاوية HTML في كتلة ثم تحاول إغلاقها بعد مكوّنات Streamlit؛ وهذا كان سبب الشريط الأبيض والفراغات وانفصال بطاقات المسار.
- نُقلت لوحة الطالب كاملة إلى مكوّن محلي معزول داخل Streamlit، لذلك لا يستطيع DOM أو CSS الخاص بـStreamlit تفكيك التصميم.
- يظهر الهيدر والـHero ومؤشر 30% والإحصاءات والمسار الأفقي وبطاقات الوحدات في بنية واحدة متماسكة.
- تعمل أزرار الإعدادات والتنقل إلى المراحل وتنزيل ZIP من داخل الواجهة الجديدة.
- جميع ملفات HTML وCSS وJavaScript محلية، بلا CDN أو خطوط خارجية.
- التصميم متجاوب على الهاتف، مع سحب أفقي للمراحل بدل تكديس الصفحة.
- صُحح النص إلى: «انقطاع الشبكة» دون محارف تالفة.

التحقق المنفذ:
- اختبار بروتوكول Streamlit Components وتمرير البيانات والإجراءات.
- اختبار بصري فعلي للمكوّن في Chromium على سطح المكتب والهاتف.
- التحقق من وجود الهيدر والـHero وأربع مراحل وبطاقة نشطة عريضة وعدم وجود حاوية فارغة.
- التحقق من RTL ومنع التمرير الأفقي للصفحة على الهاتف.
- فحص Python وUTF-8 وعدم وجود تبعيات واجهة بعيدة.

التشغيل:
1) فك ضغط الحزمة كاملة.
2) افتح المجلد في الطرفية.
3) نفّذ: pip install -r requirements.txt
4) شغّل: python -m streamlit run app.py
