ملفات التحديث v27 — منصة الطالب الصامد (فيديوهات تعليمية)
===============================================================

1) قسم «مراجعة الدرس» لوحدة الزخم الخطي والدفع:
   أُضيف قسم «🎥 فيديوهات شرح الوحدة» فيه خمسة فيديوهات مرتبة في تبويبات:
   1. الزخم الخطي: المفهوم والعلاقة P = mv
   2. تغير الزخم والدفع I = F·Δt
   3. العلاقة بين الدفع وتغير الزخم
   4. حفط الزخم الخطي
   5. تطبيقات وتمارين
   موقع القسم: أعلى الصفحة قبل اختيار المفهوم وخريطة المفاهيم.

2) قسم «التأسيس»: أُضيف فيديو تأسيسي واحد في قسم «🎥 فيديو تأسيسي».

3) يعمل في المنصة (Streamlit) وفي نسخة PWA / الأوفلاين معاً:
   - في Streamlit: مشغل فيديو داخلي مع رابط «فتح على يوتيوب».
   - في PWA: مشغل مدمج (youtube-nocookie) مع تبويبات ورابط خارجي.
   - ملاحطة: تشغيل الفيديو يحتاج اتصالاً بالإنترنت (بقية المحتوى يعمل أوفلاين).

4) إضافة فيديو جديد لاحقاً سهلة: في ملف review_content.py داخل PHYSICS_REVIEW
   توجد قائمة "videos" — أضف سطراً مثل:
   {"id": "XXXX", "title": "عنوان الفيديو", "url": "https://www.youtube.com/watch?v=XXXX"},
   وللأوفلاين أضف نفس السطر في نهاية unit-physics-review-data.js.

5) تحديث الكاش إلى samed-core-v27 + إعادة بناء حزم الأوفلاين.

ارفع الملفات الثلاثة عشر بنفس المسارات داخل المخزن ثم اضغط Commit changes.
